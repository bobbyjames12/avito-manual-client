# Авито · Ручной клиент для Windows

Локальное приложение PySide6 для ручного создания объявлений о мужских кофтах и футболках.
Не требует браузера, веб-сервера или установленного Python при запуске готовой сборки.

## Запуск готовой версии

Распакуйте **всю** папку из `dist/AvitoManualClient-Windows.zip` и запустите
`AvitoManualClient/AvitoManualClient.exe`. Папка `_internal` должна оставаться рядом с EXE.
Это переносимая сборка, а не установщик. Поддерживается Windows x64.

## Как пользоваться

1. Нажмите «Новое объявление», заполните поля и добавьте JPG/PNG.
2. Выберите главное фото, переместив его на первое место. Черновик сохраняется автоматически.
3. Нажмите «В очередь / обновить». Локальная проверка покажет незаполненные поля.
4. В «Меню → Настройки подключения» укажите endpoint, бакет, регион, публичный URL корня бакета и ключи.
   Пример публичного URL: `https://storage.yandexcloud.net/имя-бакета`.
   Endpoint в этом примере: `https://storage.yandexcloud.net`.
5. Оставьте отдельную автоматически созданную папку клиента. Она не должна совпадать
   с папкой существующего пайплайна. Настройте публичное чтение объектов этой папки;
   весь бакет открывать необязательно. ACL public-read нужен только для провайдеров,
   которые используют объектные ACL; по умолчанию ожидается настроенная политика чтения.
6. Нажмите «Отправить очередь». Клиент отправит фото, проверит доступность ссылок
   без авторизации, затем заменит полный XML-фид и проверит его публичное содержимое.
7. Постоянную ссылку `…/feed.xml` из настроек один раз укажите в автозагрузке Авито.
   XML или ZIP вручную на Авито загружать не нужно. Фото тоже передаются по ссылкам.
8. Дождитесь обработки в Авито и проверьте его отчёт. Клиент можно закрыть после
   отправки: файлы остаются в S3.

Редактирование: откройте отправленную карточку, измените текст/фото, нажмите
«В очередь / обновить», затем «Отправить очередь». ID сохраняется. До этого
в фиде остаётся предыдущая отправленная версия. Новая партия не удаляет
предыдущие объявления из фида без явного удаления.

## Данные и ограничения первой версии

- База SQLite и копии фотографий: `%LOCALAPPDATA%\AvitoManualClient`.
- Один компьютер, один фид, один аккаунт; второй экземпляр блокируется.
- Ключи S3 защищены Windows DPAPI для текущего пользователя, не хранятся открытым текстом.
- «Резервная копия» сохраняет согласованную базу и фото в ZIP. Для восстановления
  закройте приложение и распакуйте содержимое в папку данных, предварительно сохранив
  её текущую копию. Перенос на другого пользователя/компьютер требует повторного ввода ключей.
- Статус «Отправлено в S3» означает только доступность фида. API статусов Авито,
  запуск обработки через API и импорт старых объявлений пока не реализованы.
- Поддерживается мужская одежда → кофты и футболки. Проверенные справочники описаны ниже.
- Не перенесены автоматические подстановки остатков, примерки и генерация контента.
- Адрес фида закрепляется после первой попытки отправки. Перенос хранилища требует
  отдельной миграции. Повтор после ошибки использует тот же фид и те же ID.
- Если на аккаунте уже работает пайплайн, сначала определите, какой фид должен
  управлять объявлениями. Подмена существующей ссылки без переноса старых объявлений
  не является миграцией; общий фид двух программ в этой версии не реализован.

## Разработка и проверки

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_*.py -v
.\.venv\Scripts\python.exe tests\smoke_ui.py
.\build.ps1
```

Основные тесты проверяют версии очереди, сохранение прежних объявлений в полном фиде,
обрыв отправки, запрет обновления XML при недоступном фото, неизменяемые фотографии
и резервную копию. Smoke-тест проверяет нативное окно, ввод, очередь, дублирование
и DPAPI без реальной отправки в S3/Авито.

## Проверки полей (версия 0.2.0)

Справочники взяты из официального XLSX-шаблона Авито для категории
«Мужская одежда → Кофты и футболки», включённого в отчёт от 10.09.2026.
Файл `avito_client/catalog.json` содержит только справочники, без объявлений и контактов.
Страницы https://autoload.avito.ru/format/lichnye_veschi/ и каталог брендов
https://avito.ru/web/1/catalogs/content/feed/brendy_fashion.xml были недоступны
при проверке 11.09.2026. Полной онлайн-проверки всех правил площадки не было.

Поддерживаются 10 подвидов, включая худи; 7727 значений бренда, 24 размера,
4 состояния, 17 цветов, 73 материала, тип объявления и способ связи из шаблона.
Ошибки видны рядом с полями и по кнопке «Проверить». Проверяется весь фид перед
отправкой, включая предыдущие отправленные карточки. Старые неверные значения
не заменяются молча: их нужно исправить и заново добавить карточку в очередь.

Доставка: Выключена, ПВЗ, Курьер, Постамат. Можно выбрать несколько способов,
но «Выключена» не сочетается с остальными. Собственные перевозчики из справочника
показаны недоступными: для них нужны дополнительные настройки, пока не реализованные.
Доставка и материалы передаются в XML как списки элементов Option.

Проверяются обязательные поля, длина заголовка (50), описания (7500), имени (40),
адреса (256), числовая цена, формат телефона, до 10 фото JPEG/PNG по 25 МБ.
Модерация содержания, актуальность бренда в живом справочнике, тариф, подтверждение
номера, география и доступность доставки в конкретном аккаунте остаются проверками Авито.
Женская одежда и другие категории не включены в этот проверенный шаблон.

## Удаление и упрощённый интерфейс (0.3.0)

Карточка разделена на вкладки: «Объявление», «Параметры», «Доставка и контакты».
История, резервные копии и подключение находятся в меню. Черновики сохраняются автоматически.

Чтобы удалить карточку из автозагрузки, выберите её → «Действия → Удалить из автозагрузки» →
подтвердите → «Отправить очередь». Карточка исключается из полного XML, остальные сохраняются.
Можно отправить пустой фид при удалении последнего объявления. Если Авито отклонит пустой
фид, проверьте отчёт и снимите последнее объявление через кабинет Авито.
Клиент подтверждает только изменение XML в S3, а не снятие с публикации на Авито.
Правила снятия на стороне Авито не удалось повторно проверить онлайн: официальная документация недоступна.

При ошибке отправки удаление остаётся в очереди. Карточку можно найти в фильтре «Удалённые»
и восстановить через «Действия → Восстановить карточку». После успешного удаления возвращённую
карточку нужно снова добавить в очередь. Фотографии и история локально сохраняются.

## Обновления

Начиная с 0.3.0 клиент проверяет последний стабильный релиз своего GitHub-репозитория при запуске.
При наличии новой версии появляется кнопка «Обновить клиент». Скачать, проверить SHA-256,
распаковать, проверить запуск новой EXE и перезапустить программу клиент умеет сам.
Можно вызвать проверку через меню. Ошибка сети не мешает работе с объявлениями.

Первый переход с 0.2.0 требует один раз скачать и полностью распаковать новую версию.
Обновление сохраняет базу и ключи в LOCALAPPDATA, а также переносит личный settings.avitoconfig,
если он лежит рядом с EXE. Публичный релиз не содержит личных ключей.
Папка программы и её родительская папка должны быть доступны на запись.
Предыдущая версия остаётся рядом в папке *.previous-*; ошибка установки записывается
в %LOCALAPPDATA%\AvitoManualClient\update-error.txt. Во время скачивания и замены файлов
отправка объявлений блокируется. После обновления используется тот же путь к EXE.
